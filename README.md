
# College Admin Panel

This the app for the admin side. 
He can upload a notice, 
Create a new announcemnt. 
Publish Some new Content etc.
## Features

- Light/dark mode toggle
- Update Faculty/staff information
- Allow to upload photos and pdfs 
- Track Attendance
- Easy UI 
- Login Feature (static/constant password)


## Tech Stack

Java
Android 
Postgres
